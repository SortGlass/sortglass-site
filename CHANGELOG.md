# SortGlass Website Changelog

## Unreleased

### Fixed

- Made every tour screen reachable by keyboard, with named tabs/panels and inactive content removed from keyboard/screen-reader access.
- Improved small-text contrast and heading hierarchy; kept tour text readable during scrolling and wrapped narrow-screen selectors.
- Corrected demo completion focus, hidden controls, and canceled gestures; provided a Previous button as an alternative to dragging.
- Kept video controls consistent with playback state and honored changes to Reduce Motion. Limited the decorative gesture hint to two cycles.
- Kept text visible if the site script fails to load.

### Added

- Restrictive page content policies, a no-referrer policy, an accessibility information/contact page, and focused regression tests.

### Changed

- Qualified absolute privacy, deletion-safety, and undo claims; disclosed external App Store badge image requests. Policy copy remains subject to owner/legal review before publication.
